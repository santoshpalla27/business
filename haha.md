File
What it is: The main menu used to create, open, save, export, and manage Photoshop documents.
How to use: Click File in the top menu bar to access document and automation commands.
Example: Used to create a new project or save your finished design.

New
What it is: A command that creates a new blank Photoshop document.
How to use: Click File → New and set the size, resolution, and color mode.
Example: Used to create a 1920×1080 canvas for a YouTube thumbnail.

Open
What it is: A command that opens an existing file in Photoshop.
How to use: Click File → Open and select the image or PSD file.
Example: Used to edit a photo downloaded from your camera.

Browse in Bridge
What it is: A command that opens Adobe Bridge to manage and browse files.
How to use: Click File → Browse in Bridge to open the file browser.
Example: Used to view and organize many photos before editing.

Open As
What it is: A command that opens a file using a specific file format.
How to use: Click File → Open As and choose the format type.
Example: Used when opening a file as a RAW or different format.

Open As Smart Object
What it is: A command that opens a file as a Smart Object layer.
How to use: Click File → Open As Smart Object and select the file.
Example: Used to keep image quality while resizing or transforming.

Open Recent
What it is: A list of recently opened Photoshop files.
How to use: Click File → Open Recent and choose a file from the list.
Example: Used to quickly reopen a project you edited earlier.

Close
What it is: A command that closes the current open document.
How to use: Click File → Close or press Ctrl/Cmd + W.
Example: Used when you finish editing one image.

Close All
What it is: A command that closes all open Photoshop documents.
How to use: Click File → Close All to close every open file.
Example: Used when ending your editing session.

Close Others
What it is: A command that closes all documents except the active one.
How to use: Click File → Close Others while one document is active.
Example: Used when many images are open but you need only one.

Save
What it is: A command that saves changes to the current file.
How to use: Click File → Save or press Ctrl/Cmd + S.
Example: Used to save progress while editing a PSD file.

Save As
What it is: A command that saves the file with a new name or format.
How to use: Click File → Save As and choose the new location or format.
Example: Used to save a PSD as a JPEG.

Save a Copy
What it is: A command that saves a duplicate copy of the document.
How to use: Click File → Save a Copy and select the format and location.
Example: Used to keep the original PSD while exporting another version.

Export
What it is: A menu used to export files in different formats and settings.
How to use: Click File → Export and choose the export method.
Example: Used to export a design for web or social media.

Quick Export as PNG
What it is: A fast command that exports the image as a PNG file.
How to use: Click File → Export → Quick Export as PNG.
Example: Used to quickly export a logo with transparency.

Export As
What it is: A tool that exports images with custom format and quality settings.
How to use: Click File → Export → Export As and adjust format and size.
Example: Used to export optimized images for websites.

Save for Web (Legacy)
What it is: An older tool used to optimize images for web use.
How to use: Click File → Export → Save for Web and choose compression settings.
Example: Used to reduce image size for faster website loading.

Generate
What it is: A feature that automatically creates assets from layers.
How to use: Enable File → Generate and name layers with file extensions.
Example: Used to export UI icons automatically.

Image Assets
What it is: A feature that exports individual layers as image files.
How to use: Enable File → Generate → Image Assets and name layers properly.
Example: Used to export multiple design elements quickly.

Share
What it is: A command that shares the image to apps or services.
How to use: Click File → Share and choose a supported service.
Example: Used to send an image directly to email or cloud services.

Automate
What it is: A menu containing tools for automating repetitive tasks.
How to use: Click File → Automate and choose a specific automation tool.
Example: Used to process many images automatically.

Batch
What it is: A tool that applies an action to multiple files at once.
How to use: Click File → Automate → Batch and select files and actions.
Example: Used to resize hundreds of images automatically.

Create Droplet
What it is: A tool that creates a small executable file for batch actions.
How to use: Click File → Automate → Create Droplet and assign an action.
Example: Used to drag images onto the droplet to process them.

Contact Sheet II
What it is: A tool that creates a grid of multiple images in one document.
How to use: Click File → Automate → Contact Sheet II and select images.
Example: Used to display many photos on a single page.

Photomerge
What it is: A tool that combines multiple photos into a panorama.
How to use: Click File → Automate → Photomerge and select images.
Example: Used to stitch landscape photos into a wide panorama.

Merge to HDR Pro
What it is: A tool that combines images with different exposures into HDR.
How to use: Click File → Automate → Merge to HDR Pro and select photos.
Example: Used to create a balanced image from bright and dark shots.

Crop and Straighten Photos
What it is: A tool that automatically crops and straightens multiple photos.
How to use: Click File → Automate → Crop and Straighten Photos.
Example: Used when scanning many photos on one page.

Scripts
What it is: A menu for running automation scripts in Photoshop.
How to use: Click File → Scripts and choose a script to run.
Example: Used to automate complex editing tasks.

Image Processor
What it is: A script that converts and resizes many images at once.
How to use: Click File → Scripts → Image Processor and select files.
Example: Used to convert many RAW photos to JPEG.

Script Events Manager
What it is: A tool that runs scripts automatically during certain events.
How to use: Click File → Scripts → Script Events Manager and assign a script.
Example: Used to run a script automatically when opening a file.

Browse
What it is: A command that opens Adobe Bridge to browse files.
How to use: Click File → Browse to open the file manager.
Example: Used to quickly locate images on your computer.

File Info
What it is: A panel that shows and edits metadata of the file.
How to use: Click File → File Info and edit information fields.
Example: Used to add copyright or author details.

Print
What it is: A command that prints the current document with settings.
How to use: Click File → Print and adjust printer options.
Example: Used to print a photo on photo paper.

Print One Copy
What it is: A quick command that prints one copy using default settings.
How to use: Click File → Print One Copy.
Example: Used to quickly print a document without changing settings.

Exit / Quit
What it is: A command that closes Photoshop completely.
How to use: Click File → Exit or Quit.
Example: Used when you finish working in Photoshop.

Edit
What it is: The main menu that contains commands for editing content and transformations.
How to use: Click Edit in the top menu to access editing and transform tools.
Example: Used to undo changes or transform a selected object.

Undo
What it is: A command that reverses the last action you performed.
How to use: Click Edit → Undo or press Ctrl/Cmd + Z.
Example: Used to cancel a mistaken brush stroke.

Step Forward
What it is: A command that moves forward in the history after undoing.
How to use: Click Edit → Step Forward or press Shift + Ctrl/Cmd + Z.
Example: Used to redo an action that was undone.

Step Backward
What it is: A command that moves back one step in the history panel.
How to use: Click Edit → Step Backward or press Ctrl/Cmd + Alt + Z.
Example: Used to undo multiple previous actions.

Fade
What it is: A command that reduces the strength of the last applied effect.
How to use: Click Edit → Fade and adjust the opacity or blend mode.
Example: Used to reduce the intensity of a filter or brush stroke.

Cut
What it is: A command that removes the selected pixels and copies them to the clipboard.
How to use: Select an area and click Edit → Cut or press Ctrl/Cmd + X.
Example: Used to move an object to another layer.

Copy
What it is: A command that copies the selected pixels to the clipboard.
How to use: Select an area and click Edit → Copy or press Ctrl/Cmd + C.
Example: Used to duplicate part of an image.

Copy Merged
What it is: A command that copies the visible result of all layers.
How to use: Select an area and click Edit → Copy Merged.
Example: Used to copy the final combined image from multiple layers.

Paste
What it is: A command that inserts copied pixels into the document.
How to use: Click Edit → Paste or press Ctrl/Cmd + V.
Example: Used to place a copied object into a new layer.

Paste Special
What it is: A menu that pastes content using special placement options.
How to use: Click Edit → Paste Special and choose the paste method.
Example: Used to paste content exactly where it was copied from.

Paste in Place
What it is: A command that pastes copied content in the same position.
How to use: Click Edit → Paste Special → Paste in Place.
Example: Used when copying between documents with the same layout.

Paste Into
What it is: A command that pastes content inside a selection as a mask.
How to use: Make a selection and click Edit → Paste Into.
Example: Used to place a texture inside a shape.

Clear
What it is: A command that deletes selected pixels without copying them.
How to use: Select an area and click Edit → Clear or press Delete.
Example: Used to remove unwanted parts of an image.

Check Spelling
What it is: A tool that checks spelling in text layers.
How to use: Click Edit → Check Spelling to scan text for errors.
Example: Used to fix spelling mistakes in a poster.

Find and Replace Text
What it is: A tool that searches and replaces words in text layers.
How to use: Click Edit → Find and Replace Text and enter the words.
Example: Used to change a repeated word across many text layers.

Fill
What it is: A command that fills a selection with color, pattern, or content.
How to use: Select an area and click Edit → Fill and choose the fill type.
Example: Used to fill a background with solid color.

Stroke
What it is: A command that adds a colored border around a selection.
How to use: Select an area and click Edit → Stroke and choose width and color.
Example: Used to create a border around a shape.

Content Aware Fill
What it is: A tool that fills selected areas using surrounding image content.
How to use: Select an object and click Edit → Content Aware Fill.
Example: Used to remove unwanted objects from photos.

Puppet Warp
What it is: A tool that bends and moves parts of an image using control pins.
How to use: Click Edit → Puppet Warp and drag pins to reshape areas.
Example: Used to adjust the position of arms in a photo.

Free Transform
What it is: A tool that resizes, rotates, and moves a layer or selection.
How to use: Select a layer and press Ctrl/Cmd + T to transform it.
Example: Used to resize a logo in a design.

Transform
What it is: A menu containing different transformation tools.
How to use: Click Edit → Transform and choose a transform type.
Example: Used to modify the shape or position of objects.

Scale
What it is: A transform option that changes the size of a layer.
How to use: Click Edit → Transform → Scale and drag the handles.
Example: Used to enlarge or reduce an image.

Rotate
What it is: A transform option that rotates a layer or selection.
How to use: Click Edit → Transform → Rotate and drag to rotate.
Example: Used to straighten a tilted object.

Skew
What it is: A transform option that tilts the edges of a layer.
How to use: Click Edit → Transform → Skew and drag corner handles.
Example: Used to match perspective of flat objects.

Distort
What it is: A transform option that moves each corner independently.
How to use: Click Edit → Transform → Distort and drag corners.
Example: Used to fit an image onto a surface like a billboard.

Perspective
What it is: A transform option that changes perspective by moving corners together.
How to use: Click Edit → Transform → Perspective and drag corners.
Example: Used to simulate depth in objects.

Warp
What it is: A transform tool that bends an image using a grid.
How to use: Click Edit → Transform → Warp and drag grid points.
Example: Used to curve text or graphics.

Define Brush Preset
What it is: A command that saves an image or shape as a brush.
How to use: Select the area and click Edit → Define Brush Preset.
Example: Used to create custom stamp brushes.

Define Pattern
What it is: A command that saves a selection as a repeating pattern.
How to use: Select an area and click Edit → Define Pattern.
Example: Used to create repeating textures.

Define Custom Shape
What it is: A command that saves a shape as a reusable custom shape.
How to use: Select a shape and click Edit → Define Custom Shape.
Example: Used to reuse logos or icons.

Purge
What it is: A command that clears temporary memory like clipboard or history.
How to use: Click Edit → Purge and choose the memory type to remove.
Example: Used to free RAM when Photoshop becomes slow.

Presets
What it is: A menu that manages saved brushes, gradients, and patterns.
How to use: Click Edit → Presets and choose the preset manager.
Example: Used to load or delete brush presets.

Preferences
What it is: A menu that controls Photoshop settings and behavior.
How to use: Click Edit → Preferences and adjust the options.
Example: Used to change performance or interface settings.

Example: Used to convert an image from RGB to CMYK for printing.
