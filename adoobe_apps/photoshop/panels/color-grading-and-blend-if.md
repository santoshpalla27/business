# Color Grading in Adobe Photoshop 

## What is Color Grading?

### Beginner meaning:
Color grading means adjusting colors to create a mood or cinematic look.

You are not fixing the photo.
You are stylizing it.

### Example:

Warm orange look → sunset / cinematic

Cool blue look → moody / night feel

Green tint → thriller mood

Soft pastel → Instagram aesthetic




## Professional Color Grading Workflow (Industry Standard)

Always work non-destructively using Adjustment Layers.

### Step 1 – Fix First (Base Correction)

Before grading:

Exposure correct
White balance correct
Contrast balanced

Use:

Camera Raw Filter
Curves
Levels
Grading comes AFTER correction.





## Main Tools for Color Grading

### 1️⃣ Curves (Most Powerful Tool)

Use RGB channels separately.

Red channel → add red / remove cyan
Green channel → add green / remove magenta
Blue channel → add blue / remove yellow

Cinematic trick:

Add slight blue in shadows
Add slight orange in highlights
This creates the classic teal-orange look.

### 2️⃣ Color Balance

Best for quick grading.

Shadows → cool
Midtones → neutral
Highlights → warm

Used heavily in:

YouTube thumbnails
Instagram reels
Product ads

### 3️⃣ Gradient Map (Advanced Look)

This maps:

Dark areas → one color
Light areas → another color

Example:

Shadows → dark blue
Highlights → light orange

Set blend mode to:

Soft Light
Overlay
Color
Lower opacity to 20–50%.

Very powerful for cinematic work.


4️⃣ Selective Color (Advanced Retouching)

Used in:

Fashion

E-commerce
Brand editing

Example:

Increase blacks in neutrals
Adjust yellow in whites
Remove green from skin tones

Very precise tool.

### Blend If (Hidden Power Tool)

Now we go advanced.

What is Blend If?

Blend If allows a layer to appear only in certain brightness areas.

It blends based on:

Highlights
Shadows
Specific tonal ranges
WITHOUT masking.

Where to Find It?

Double click a layer → Layer Style panel → Bottom section → Blend If

How It Works
There are two sliders:

This Layer
Controls visibility of the current layer.

Underlying Layer
Controls how it blends with layers below.

also use alt + adjust the slider to get accurate results 


### Why Professionals Love Blend If

✔ No destructive masking
✔ Fast
✔ Very clean transitions
✔ Works beautifully with grading layers



Advanced Pro Tip (High-End Retouching)

Use Blend If with:

Dodge & Burn layers

Texture overlays

Skin retouching

Cinematic light leaks

Combine with Smart Objects for full non-destructive workflow.
