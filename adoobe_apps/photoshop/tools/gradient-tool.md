Gradient Tool in Adobe Photoshop

The Gradient Tool in Adobe Photoshop creates a smooth transition between two or more colors across a selected area or layer.

What It Does

It blends colors gradually instead of filling with a single solid color.

Example:

Black → White fade
Transparent → Color fade
Red → Blue → Yellow multi-color blend

Types of Gradients (Top Options Bar)

Linear Gradient
Straight line blend (most commonly used).

Radial Gradient
Circular blend from center outward.

Angle Gradient
Rotates colors around a center point.

Reflected Gradient
Mirror effect from center.

Diamond Gradient
Diamond-shaped transition.

How to Use It (Basic Workflow)

Select a layer.

Press G.

Choose gradient type from top bar.
Click and drag across canvas.
Longer drag = smoother transition.
Short drag = sharper blend.

Gradient Editor (Important)

Click the gradient preview bar in the top options → opens Gradient Editor.

Here you can:

Add multiple colors
Adjust color stops
Change opacity stops
Save custom gradients

Foreground to Background Gradient

Very common setting:

Uses your current foreground & background colors.
Good for overlays, lighting effects, background design.

Transparent Gradients

Used for:

Soft fades
Light effects
Mask blending

Tip: Use gradient on a Layer Mask to blend images smoothly.

Advanced Use Cases (Important for Designers)
