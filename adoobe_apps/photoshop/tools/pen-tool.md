                  Pen Tool in Adobe Photoshop

The Pen Tool is a vector-based path creation tool used for:

Precise cutouts (hair, products, cars)
Creating custom shapes
Making clipping paths
Advanced masking
Logo & typography shaping

It works with anchor points + Bézier curves.

1️⃣ Where to Find It

Shortcut: P

Tool group includes:

Pen Tool – Creates precise straight and curved vector paths using anchor points and Bézier handles.

Freeform Pen Tool – Draws paths freely like a pencil, automatically placing anchor points as you drag.

Add Anchor Point Tool – Inserts a new anchor point on an existing path segment for more control.

Delete Anchor Point Tool – Removes an anchor point from a path to simplify or reshape it.

Convert Point Tool – Changes an anchor point between smooth (curved) and corner (sharp) by adjusting or removing direction handles.

2️⃣ How It Actually Works (Core Concept)

Every path is made of:

Anchor Points → Fixed points
Direction Handles → Control curve shape
Path Segments → Lines between points

Two main clicks:

| Action       | Result        |
| ------------ | ------------- |
| Click once   | Straight line |
| Click + drag | Curved line   |

3️⃣ Basic Usage (Step-by-Step)

✏️ Drawing Straight Lines

Select Pen Tool (P)

Click → creates first anchor
Click somewhere else → straight line
Press Enter → finish path

Drawing Curves

Click and drag → creates curved anchor
Click and drag next point → adjust curve
Adjust handles for smooth shape

4️⃣ Tool Modes (VERY Important)

In top bar you’ll see:

Shape
Path
Pixels

✔ Use "Path" for:

Cutouts & masking (professional retouching workflow)

✔ Use "Shape" for:

Vector shapes (icons, UI elements)

❌ Avoid "Pixels"

Unless you specifically want raster drawing.

5️⃣ How to Cut Out an Object (Professional Way)

Set mode to Path
Trace object carefully
Right click → Make Selection
Add Layer Mask

OR

Right click → Create Vector Mask (cleanest method)

6️⃣ Difference: Layer Mask vs Vector Mask

| Layer Mask           | Vector Mask            |
| -------------------- | ---------------------- |
| Pixel based          | Vector based           |
| Can blur edges       | Always sharp           |
| Resolution dependent | Resolution independent |

Use Vector Mask when you want crisp edges (product, car, logo).

7️⃣ Convert Sharp to Curve

Use Convert Point Tool (inside Pen group)

Click on anchor → makes it sharp
Drag on anchor → makes it curved

8️⃣ Common Beginner Problems

❌ Curve going wrong direction?

Hold Option (Alt) and drag one handle separately.

❌ Can't move points?

Use A (Direct Selection Tool)

White arrow = move individual anchor
Black arrow = move whole path

9️⃣ Industry Workflow Tip

Professional retouchers:

Zoom 200–300%
Use minimal anchor points
Place anchors at direction change points
Keep handles balanced
Less points = smoother curve.
