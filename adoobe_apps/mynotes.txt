mask is used to hide or show the part of the image which we want.

mask has two things black and white .. black hides and white shows   gray is like 50% hide and 50% show

shortcut :- x.   --  to toggle between black and white.

mask clipping is used to style the only layer which we want to style. we create a new layer above the masked layer and make the mask clipping to the new layer. and clip this layer with masked layer. now the changes in this layer like color correction or style or some text of background will be applied to the below layer 

but the thing will mask clipping is it will be applied to the below layer only. it will not be applied to the above layer.
and also the below layer mask subject (black section) will only get the changes and syling from the  above layer.

we should transform and adjust the mask layer to get the desired result. 

shortcut :- shift + cmd and hover on layer bottom you will be option for clipping

           selection tool

click and hold the tools to get more options 

selection tool is used to select the area which we want 
then we can mask or remove or create a new layer or remove the selected area from the layer etc 

there are different types of selection tools :-

marquee tools (m) - geometric precision
lasso tools (l) - manual selection
quick selection tool (w) - ai brush selection
object selection tool - modern ai selection

marquee tools (m) :- 
rectangular marquee - creates rectangular selections.
elliptical marquee - creates circular/oval selections.
single row - selects 1-pixel row or column.
single column - selects 1-pixel row or column.

lasso tools (l) :- 

lasso (freehand) - Draw freeform selections.
polygonal lasso (straight edges) - Click-based straight-line selections.
magnetic lasso (edge detection) - Snaps to edges.
