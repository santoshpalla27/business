

layer are like a stack of images, where each image is called a layer.  

so this will be easy to edit the image, as we can edit each layer separately.


with normal layer if we edit the image, it will lose the qulity will increase and decrease of the image.
and the changes will be permanent.like erasing or bushes or color correction will be permanent.

smart object is like a layer which is protected from the edits and all the edits maded are added kind of adons to the smart object called smart filter

with smart object the main image will be protected 
so no quality loss will be there. and all the changes we make will be non-destructive. and saved as smart filter (think of it like layers inside a layer)

so the changes are not permanent we can edit the smart object again and again.

i we want to make in the smart object then we can double click the smart object layer i will open as normal we make changes save and comeback and changes will be reflected.in tha main section

====================
             mask 

you can add mask to a layer but clicking the mask option (window with circle in it)  below in the bar
mask is an addition to a layer that is used to hide or show the desired part of the image below it.

think of it like real mask hide what we dont want to show 
mask is used to hide or show the part of the image which we want.

mask has two things black and white .. black hides and white shows  

shortcut :- x.   --  to toggle between black and white. 

] is used to increase the size of the brush
[ is used to decrease the size of the brush

mask works best with smart object which makes a deadly combo of non destructive editing 

***
use selection tools to select the area you want to mask or can also use brush 

cmd + i by selecting the mask = invert the mask  or can directly create opposite mask by using alt + click on the mask icon 


shift  + click on the mask = disable the mask 
shift  + click on the mask again = enable the mask 

used to see how it looks without mask without deleting completely 

***

two types :- 

Layer Mask → Organic / soft / painted
Vector Mask → Sharp / geometric / precise

🧠 Example

Hair cutout → Layer mask
Logo cutout → Vector mask
Product edge → Vector mask
Shadow fade → Layer mask

         mask linking and unlinking 

you have a small icon in between layer and mask use that to lock or unlock 
generally if the mask is locked and if we move that layer the mask will not be moved so it will be in the same position .
so we first unlink the mask and move the layer and then relink the mask  


mask clipping is used to style the only layer which we want to style. we create a new layer above the masked layer and make the mask clipping to the new layer. and clip this layer with masked layer. now the changes in this layer like color correction or style or some text of background will be applied to the below layer 

but the thing will mask clipping is it will be applied to the below layer only. it will not be applied to the above layer.
and also the below layer mask subject (black section) will only get the changes and syling from the  above layer.

we should transform and adjust the mask layer to get the desired result.
